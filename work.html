Selected projects

Prompt Palette

My prompts kept getting scattered across notes and tabs, so I built a TypeScript browser extension to keep them in reach.

It stores prompts locally, organizes them with tags, and lets you select and copy several at once using the keyboard.
You can open your library from the page you’re already working on.

View Repository Usage Guide Issues & Feedback

Chord Function API

I turned a music theory question—what role does this chord play in this key?—into a JavaScript tool with a Node.js and Express API.
It takes a key, chord root, and quality and returns a Roman-numeral chord label.

I also published the calculation logic as an npm package for use in other music software.

View Repository API Docs npm Package

Sage & Cedar

For this salon site, I adapted a responsive HTML/CSS layout to bring service prices, opening hours, and team information into one page.

I grouped the treatment menu by service and paired it with photography, giving visitors a way to explore the salon and find practical details on a phone.

Flowers by Leanne

I built a responsive florist site around photographs of the arrangements, with sections for weddings and celebrations of life.
The page introduces the person behind the work, shows the occasions she caters for, and leads into contact details.

I handled the layout and mobile styling so the images and service information work together on smaller screens.

Fridge Poetry Lab

A fridge-magnet writing board I built as a standalone JavaScript web component.
You can search and filter the word bank, arrange magnets with a mouse, touch, or keyboard, and return to a saved layout.

The same component can be embedded on another site with a custom word list.

A little background

I’ve written software for local IT, music technology, and real estate businesses, and for international fashion brands.
My public work includes TypeScript browser tools, JavaScript interfaces, and Node.js APIs.
I also use Go, Python, and shell scripts for smaller utilities and automation.

I stay involved after the first version.
Using Prompt Palette and incorporating feedback has meant revisiting its interface and the small steps involved in saving and reusing prompts.

On this site, I’ve put browser, accessibility, and performance checks into the publishing workflow.
Writing usage guides and making components reusable are part of that work, too: someone else should be able to pick up what I’ve built and use it.
