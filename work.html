Prompt Palette

My prompts kept getting scattered across notes and tabs, so I built a TypeScript browser extension to keep them in reach.

It stores prompts locally, organizes them with tags, and lets you select and copy several at once using the keyboard.

You can open your library from the page you’re already working on.

Chord Function API

It started with a music theory question: what role does this chord play in this key? I turned the answer into a JavaScript tool backed by a Node.js and Express API.

Give it a key, a chord root, and a chord quality, and it returns the chord’s Roman numeral.

I also published the calculation logic as an npm package for use in other music software.

View Repository API Docs npm Package

This Site

I started from a free HTML template and kept rewriting it until almost none of the original was left. It’s still plain HTML, CSS, and JavaScript with no build step.

There are 29 themes, from an MS-DOS prompt to a Nutrition Facts label. You get a random one each time you visit, or you can pick one and keep it.

Before anything gets published, it’s tested in Chromium, Firefox, and WebKit, scanned for accessibility problems, and checked against Lighthouse performance budgets.

Sage & Cedar

For this salon site, I adapted a responsive HTML/CSS layout to put service prices, opening hours, and team information on one page.

I grouped the treatment menu by service and paired it with photos, so visitors can get a feel for the salon and still find prices and hours quickly on a phone.

Flowers by Leanne

I built a responsive florist site around photographs of the arrangements, with sections for weddings and celebrations of life.

It introduces Leanne, shows the occasions she does flowers for, and ends with her contact details.

I handled the layout and mobile styling so the photos and service details still read well on a phone.

Fridge Poetry Lab

A fridge-magnet writing board I built as a standalone JavaScript web component.

You can search and filter the word bank and arrange magnets with a mouse, touch, or keyboard. Your layout is saved, so you can come back to it later.

The same component can be embedded on another site with a custom word list.

A little background

I’ve written software for international fashion brands and for local IT, music tech, and real estate businesses.

My public work includes TypeScript browser tools, JavaScript interfaces, and Node.js APIs.

I also use Go, Python, and shell scripts for smaller utilities and automation.

I keep working on things after the first version ships.

Between using Prompt Palette myself and the feedback I’ve gotten, I’ve kept reworking its interface and cutting steps out of saving and reusing prompts.

This site runs browser, accessibility, and performance tests as part of publishing.

I also write usage guides and try to make components reusable, so other people can pick up what I’ve built and use it.
