A little background

Most of my public projects use TypeScript or JavaScript, including browser extensions, interfaces built with React or Vue, and APIs built with Node.js and Express. I also work with HTML, CSS, Postgres, and WordPress.

Outside those projects, I’ve used Go for command-line tools, Python and shell scripts for automation, and C, C++, Assembly, and Scheme to explore how software works underneath.
