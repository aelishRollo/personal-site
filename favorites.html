A living list

A few of my favorite things

Places to go, tools to try, and ideas to keep close. This list will change as I discover more things worth sharing.

Explore the list ↓

Mindfulness

Waking Up

Sam Harris’s app combines guided meditation with lessons and conversations about the mind.

The value: A practical way to make more room for attention and reflection. If cost is a barrier, Waking Up generously offers free membership through its scholarship program.

Explore Waking Up ↗

Place · Indianapolis

North Mass Boulder

An Indianapolis bouldering gym with climbing, fitness, a café, and space to be around people.

The value: Movement, a satisfying problem to solve, and a welcoming community all in one place.

Visit North Mass Boulder ↗

Writing & web

Derek Sivers & his website

Short, clear writing about work, music, choices, and living deliberately, collected on a personal website.

The value: Fresh ways to think, delivered with the simplicity and independence I love about the web.

Read Derek Sivers ↗

Music software

SongDrive

A songwriting and collaboration project from GitHub creator mickmister.

The value: A place for musical ideas to move from one person’s head into a shared creative process.

Find SongDrive on GitHub ↗

Open knowledge

Wikipedia

A free encyclopedia built and maintained by people around the world.

The value: An astonishing starting point for curiosity, with sources that can lead you deeper.

Explore Wikipedia ↗

Digital freedom

Free Software Foundation

A nonprofit that advocates for people’s freedom to use, study, share, and change software.

The value: A reminder that the tools we rely on should respect the people using them.

Meet the FSF ↗

Creative experiment

Oasis

Decart’s Minecraft-like AI demo generates the world in real time as you move through it.

The value: A playful glimpse of what interactive, generated worlds might become. It is a technology demo, unaffiliated with Minecraft.

Try Oasis ↗

Learning tool

Anki

Flashcards that schedule reviews for when you are likely to need them.

The value: It helps turn things I want to remember into knowledge I can actually keep.

Explore Anki ↗

Free software

GNU

The long-running project to build a free, Unix-like operating system and the tools around it.

The value: Everyday computing tools built around the freedom to understand and improve them.

Explore GNU ↗

The open web

A JavaScript environment in every browser

Open the developer console and you have a place to write and run JavaScript almost anywhere.

The value: An instant little workshop for experiments, debugging, and learning, wherever a browser is available.

Learn how to use the console ↗

Course · Free access

Learning How to Learn

Barbara Oakley and Terrence Sejnowski teach practical ideas about memory, focus, procrastination, and learning difficult things.

The value: Better ways to learn almost anything. Barbara shared a free course link; the free version does not include a certificate.

Take the free course ↗
